## Code Council v0.5.66

本版本合并上游 Claude Code Haha v0.6.0(1815 个提交),并保留 Code Council 全部本地定制。

### 上游重点更新
- **Computer Use 重构**:macOS 走原生 `cu-helper` 守护进程(AX 树、虚拟光标、窗口捕获流、客户端证明),移除每应用审批弹窗;Windows 引擎路径保留
- **IM 适配器扩展**:新增企业微信、QQ、Slack 适配器;飞书支持扫码建机器人
- **对话级 rewind**(#1273):可回滚到某个替换回合而不动文件系统
- **Trace 增强**:语义时间线、请求语义快照(截断前保留结构化请求)、缓存 token 拆分展示
- **侧边栏任务视图**:按运行状态与日期分组的会话视图
- **GLM 5.3**:智谱标准 API 与 Coding Plan 双 profile,模型默认升至 glm-5.3[1m]
- **长限流重试提示**:重试横幅显示"已达到用量或速率限制"与人类可读的等待时长
- 发布链路接入 SignPath Windows 签名(fork 发版仍走 draft 跳过签名)

### 本地定制保留(与上游冲突处的取舍)
- thinking 全量透传:所有 OpenAI 兼容通道无条件回传 reasoning_content 与 thinking 开关
- 中转通道重试(get_channel_failed / 5xx api_error)与流重试墙钟预算(≤60s)
- xhigh 推理档位(K3/兼容模型),GLM profile 与 fork 模型别名规范化协同
- 服务商 tombstone:TeamoRouter / 玄枢API / FennoAI / 七牛云AI 已弃用;接口AI 保持可选无推广;不显示赞助 featured 行
- Code Council 品牌、README 双语、全部链接指向 706412584/cc-haha
- Windows Computer Use:自定义 Python 解释器、venv 标记重建、退出项保留

### 修复
- 会话 subagent POST 路由被旧 GET-only 守卫挡住导致 405
- providerRuntimeEnv import 环导致的 TDZ 崩溃(grokOfficialProvider 测试)
- 自定义 provider 命中具体 reasoning profile 时优先生效(GLM Coding Plan 别名)
