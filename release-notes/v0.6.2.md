# Claude Code Haha v0.6.2

本次更新重点解决快速推理模型在长思考与密集工具输出期间造成的桌面端卡顿，并补齐 v0.6.1 合并后的兼容性与稳定性修复。

## 性能与体验

- 对高频 `thinking` 增量进行 50ms 合并，显著减少长推理过程中的消息数组复制、文本拼接和界面重渲染。
- 思考块流式阶段改用轻量文本渲染，完成后再统一渲染 Markdown；组件加入 `memo`，滚动更新合并到动画帧。
- 活跃会话 JSONL 支持仅解析新增尾部，不再因每次轮询重复读取和解析数十 MB 的完整记录。
- 会话解析诊断日志增加按文件节流，保留慢解析与超大记录告警，同时避免诊断本身形成额外负载。

## 修复

- 修复思考缓冲在终态快照、非流式降级、停止和重连边界上的丢失、延迟复活与顺序问题。
- 修复 JSONL 最后一条完整记录尚未写入换行时，后续增量解析可能重复该记录的问题。
- 修复思考结束时待执行滚动帧被取消，导致最后一段内容未滚动到底的问题。
- 恢复 v0.6.1 合并过程中被上游覆盖的 fork 行为，包括 MCP 路由、会话恢复与 Provider 定制。
- OpenAI 兼容代理会将超过 64 字符的工具名映射为稳定短名，并在工具结果返回时恢复原名。
- 保留 DeepSeek 等推理模型所需的 thinking 内容与 relay thinking 透传。

## 安装

本次为草稿构建。Windows 与 macOS 产物可能未签名；macOS 未签名包会附带 `install-macos-unsigned.sh`。

- macOS：`Claude-Code-Haha-0.6.2-mac-arm64.dmg` / `Claude-Code-Haha-0.6.2-mac-x64.dmg`
- Windows：`Claude-Code-Haha-0.6.2-win-x64.exe` / `Claude-Code-Haha-0.6.2-win-arm64.exe`
- Linux x64：`Claude-Code-Haha-0.6.2-linux-x86_64.AppImage`、`Claude-Code-Haha-0.6.2-linux-amd64.deb` 或 `Claude-Code-Haha-0.6.2-linux-x86_64.rpm`
- Linux ARM64：`Claude-Code-Haha-0.6.2-linux-arm64.AppImage`、`Claude-Code-Haha-0.6.2-linux-arm64.deb` 或 `Claude-Code-Haha-0.6.2-linux-aarch64.rpm`

# Claude Code Haha v0.6.2

This release focuses on keeping the desktop responsive while fast reasoning models stream long thinking traces and dense tool output. It also includes compatibility and stability fixes discovered while integrating v0.6.1.

## Performance & UX

- Coalesce high-frequency `thinking` deltas on a 50 ms cadence, greatly reducing message-array copies, string concatenation and UI rerenders during long reasoning phases.
- Use lightweight text rendering while thinking streams, render Markdown once when it settles, memoize the block, and batch scroll updates into animation frames.
- Parse only newly appended JSONL bytes for active sessions instead of repeatedly reading and parsing multi-megabyte transcripts on every poll.
- Throttle per-file transcript diagnostics while preserving slow-read and oversized-transcript signals.

## Fixes

- Preserve thinking content and ordering across terminal snapshots, non-streaming fallback, stop and reconnect boundaries without resurrecting completed turns.
- Avoid duplicate records when a complete final JSONL record is observed before its terminating newline lands.
- Keep the final thinking delta scrolled into view when streaming settles.
- Restore fork behavior overwritten during the v0.6.1 merge, including MCP routes, session recovery and provider customizations.
- Map OpenAI-compatible tool names longer than 64 characters to stable wire-safe names and restore the originals on tool results.
- Preserve thinking content required by DeepSeek-style reasoning models and relay passthrough.

- Linux x64: `Claude-Code-Haha-0.6.2-linux-x86_64.AppImage`, `Claude-Code-Haha-0.6.2-linux-amd64.deb` or `Claude-Code-Haha-0.6.2-linux-x86_64.rpm`
