# v0.5.21

> 合并上游 NanmiCoder/cc-haha v0.4.3：吃到 mid-stream retry / 1M provider context / subagent 流式输出三处 bug 修复，融合 Cmd+K 全局会话搜索、模型 1M context 复选框、WorkspacePanel Navigator 切换三处新 UI；保留 cc-haha 这边 #71-#79 的 skills / project rules / agent-limiter / chat 重试去噪。

## 修复（来自上游）

- **mid-stream 流式重试**。`withRetry` 现在会识别 `api_error` / `overloaded_error` 这类没有 HTTP status 的中流错误，按 `CLAUDE_STREAM_TRANSIENT_RETRY_MAX`（默认 2）重试，避免一次工具调用半途出错就直接打断会话。配套新增 `RetriableStreamError` / `isRetryableStreamError` / `getMaxStreamTransientRetries`。
- **provider 1M context 支持**。`SavedProvider` 新增 `model1mSupport: { main, haiku, sonnet, opus }`。打开后 runtime 会把模型 ID 转成 `<model>[1m]` 形式，与上游约定的 1M context window 协议对齐。Settings 页每个模型槽下方多出一个 1M 复选框。
- **后台子代理工具活动流式回灌 desktop**。`extractAgentToolActivities(message)` 把子代理消息里的 `tool_use` / `tool_result` 块抽出来，桌面端能在子代理跑动期间看到它的工具调用进度而不是只等最终结论。

## 新功能 / UI（融合上游）

- **Cmd+K 全局会话搜索**。Sidebar 在本地过滤输入框上方加了一颗带 ⌘K 标的 “Search chats” 按钮，点开 `GlobalSearchModal`；`useKeyboardShortcuts` 把 Cmd+K 也桥接到这个 modal。我方原本的局部 filter input 行为完全不动，两个能力并存。
- **WorkspacePanel Navigator 切换**。Tab 栏右侧多出 `account_tree / right_panel_close` 切换按钮；同时把 tab 改成上游的嵌套 button 结构（`role="tab"` + `aria-selected`），可访问性更好。脏标记 `●` 仍然保留。
- **空 session hero 紧凑模式**。当底部 docked terminal 可见（`compactEmptyHero`）时，欢迎页内边距从 `pb-32` 收缩到 `pb-6`，避免被终端面板挡住。

### 新功能（追加）

- **逆向工程插件 Web 能力（0.4.6 → 0.4.9）**（#81）。新增 `web-api-recovery` 技能：从 DevTools / cURL / HAR 抓包还原内部 REST / GraphQL / batchexecute / gRPC-web API，生成可复现的 curl / httpx / fetch 客户端；内置服务端鉴权边界（IDOR / BOLA）负向测试与脱敏优先的证据处理。新增 `js-bundle-analysis` 技能：把 JS bundle / source map / Webpack 块映射到 API 面、签名 / 加密候选函数、租户 / 对象边界线索，附可选 webcrack / deob / crypto 校验工具。两者均接入 `reverse-engineer` agent 路由，可选工具仅作建议、非硬依赖。
- **项目级代理行为规则**（#81）。新增 `.claude/rules/agent-behavior.md`（skill 优先路由 / 工具前置检查 / 工件卫生 / 外部内容安全 / 任务后学习沉淀）和 `.claude/rules/plugin-development.md`（skill / agent / README / manifest 三方一致性 checklist + 验证边界）。`.gitignore` 显式 whitelist `.claude/rules/`，与既有 `.claude/agents/` 例外一致，让规则随仓库共享。
- **会话批量导出**（#81 desktop）。Sidebar 项目右键菜单新增批量导出，多会话打成 zip 一次下载，单会话保留 JSONL 直下载；导出期间按钮显示 loading 文案与禁用态，并立即触发 info toast。
- **Windows 语言服务器 smart installer**（#82）。Windows 上 LS 安装从直接注入裸 winget 命令改成走 `buildSmartInstallPlan` / `buildSmartInstallCommandLine` 构造 PowerShell EncodedCommand，与其他平台 smart-install 路径对齐；非 Windows 平台保持注入第一步安装命令的旧行为。

### 修复 / 改动（追加）

- **粘贴 / 拖拽图片自动压缩**。粘贴或拖入对话框的图片在上传前缩放到最长边 1568px、JPEG quality 0.85；GIF 不压缩以保留动画。覆盖粘贴和文件选择 / 拖拽两条路径。
- **第三方 provider 流式重试默认关闭**（360b5658）。`mid-stream retry` 默认关闭以保证第三方 provider 兼容性，避免对不支持的服务造成异常重发。
- **回退上游若干改动**（34aa9d71）。revert 上游 #823（ToolSearch beta header 强制启用）与 #703 / #707 / #712 / #751（pending tool UI / spinner 生命周期），并在 Settings 中隐藏 ToolSearch 开关；CLI 内部 host detection 仍会对非 Anthropic 直连自动关闭 ToolSearch。
- **Solo Council 卡片不再误显待机**（#55）。当 solo sub-agent 通过 tool_use 派发但 `backgroundAgentTasks` 还没落地时，`buildSoloCouncilRows()` 多了一层兜底：扫描没有对应 tool_result 的 pending Agent tool_use，合成一条 `running` 行，避免短暂窗口里卡片闪 standby。
- **服务端 JSONL 解析缓存**（#83）。会话 transcript 是 append-only JSONL，可增长到几十 MB；`readJsonlFile` 原本每次调用都做完整 `fs.readFile` + 逐行 `JSON.parse`，没有任何缓存，结果一次打开就能撞两次（`getSessionMessages` + `getSessionTaskNotifications` 同一 Promise.all 内并行读同一份文件），把 event loop 阻塞到本地接口超时甚至 send 报 fetch failed。
  - 新增按绝对路径键控的解析缓存，按 `mtimeMs + size` 失效；并发读做 in-flight de-dup，同一文件多个调用共享一次磁盘读 + 解析。
  - 字节级 insertion-order LRU 上限 64 MiB；> 16 MiB 的超大 transcript 跳过缓存以避免堆爆掉。
  - 所有 server 端写 / 删路径主动 bust 缓存键，叠加 stat-based 失效双重保险。
  - 命中返回数组浅拷贝、条目对象共享，行为对调用方透明。
