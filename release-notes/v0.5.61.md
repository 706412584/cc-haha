# Code Council v0.5.61

> 本版本完整修复后台任务停止失效和重启后卡"运行中"的问题。

## 重点更新

### 后台任务停止彻底修复

此前 v0.5.59 只补了"30秒超时解锁停止按钮"一层，另外两层被意外删除，导致：
- 点击停止后任务状态不更新（服务器已确认但 UI 纹丝不动）
- 重启 IDE 后任务仍卡"运行中"（Bun sidecar 崩溃后无终态通知写入）

本版本恢复并完善了三层完整修复：

1. **立即更新状态**（v0.5.60 已有）：服务器确认任务停止时，桌面端立即将任务标记为已停止，不再等待永远不会到来的 CLI 终态通知。

2. **终态永远覆盖 running**：`killed`/`completed`/`failed`/`stopped` 等终态通知，即使时间戳早于任务启动时间，也会强制覆盖 running 状态，而不是被丢弃。这修复了 CLI 崩溃前未能写入终态导致的卡住问题。

3. **24小时自动 kill 过期任务**：会话恢复时，运行超过 24 小时的任务自动标记为 killed。针对 Bun sidecar 段错误崩溃后重启、旧任务在 transcript 中无终态记录的情况。
