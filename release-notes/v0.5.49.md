# Code Council v0.5.49

> 本版本将上游 `v0.5.0` 合入本地产品线，建立后续持续同步上游修复的新基线。合并采用“吸收上游表现层与客观修复、保留本地产品行为”的策略。

## 主要变化

### 上游桌面 UI 与组件库

- 合入「纸·墨·印」桌面视觉重构、六套主题和系统深色/浅色外观支持。
- 引入 `components/ui` 原语层与 `components/composite` 共享组件层，统一弹窗、输入控件、菜单、空状态和可访问性行为。
- 合入可调侧边栏、紧凑会话头部、Composer 运行位置 pill、技能市场滚动加载、主题化终端配色和矢量品牌资源。
- 合入任意尺寸宠物动作表、Windows/macOS 宠物贴边与位置恢复修复。

### 上游运行时与安全修复

- 工具权限被拒绝后把结果交回模型，不再静默中断整轮。
- 在没有工具副作用时恢复传输层断流重试，并保留本地第三方 Provider 重试边界。
- 支持删除父目录 `.mcp.json` 中继承的服务器，避免把已展开凭据写回配置。
- 修复后台 Agent 活动切断流式 thinking、已删除 Task 残留活动面板、usage 重复统计等问题。
- 合入 Grok Responses 请求、Windows launcher/`taskkill`、loopback 访问边界和 Skills 多根目录解析修复。

### 保留的本地产品能力

- `solo | re | normal` 三种 Pipeline flavor、Solo Council 与实施审批门。
- Agent Office、SubAgent/Team/Task 实时活动与桌面运行状态。
- 会话内 Provider/model/thinking 切换，以及跨 Provider thinking/signature 清理。
- Stop 立即释放 turn lock、消息队列、mid-turn follow-up 与本地 stream retry 产品语义。
- H5 移动端隔离、Workspace/LSP、Skills 激活、媒体生成、IM adapters 和本地索引容量保护。
- Code Council 品牌、`706412584/cc-haha` 更新源与发布归属。

### 文档站

- 文档构建从 VitePress 迁移到独立 React `site/`，继续以 `docs/` 和 `docs/en/` 作为双语内容源。
- 下载、Issues、源码 clone 和应用更新链接继续指向本地产品仓库。

## 升级说明

- Electron Desktop：`0.5.49`
- 根 CLI 版本保持 `999.0.0-local`
- 上游 tag：`v0.5.0`
- 本地此前的 Provider、会话、Skills、Agents、记忆、自定义数据目录和 Pipeline 配置应继续保留。
- 旧主题设置由新的主题迁移逻辑处理；H5 不显示 Electron 桌面专属的宠物窗口与桌面外壳。

## 验证

发布候选需通过 Desktop、Server、Provider/Chat contract、Native、Docs、Persistence 和 Coverage 门禁；正式安装包仍需按目标平台验证签名、公证、安装与自动更新元数据。
