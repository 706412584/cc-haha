# Claude Code Haha v0.6.7

承接 v0.6.6，修掉两处中继错误处理中的边界问题。都是独立审核 v0.6.6 那批改动时发现、当时漏掉的。

## 修复

- **文档体积超限时现在会被正确剥离**。未识别的媒体拒绝兜底分支此前把**任何携带图片的 400/422** 都判为「图片不受支持」，而它只剥离图片。于是当一次请求**同时**带着图片和文档时：图片被剥掉，**文档每轮重发**，每次都撞同一个 400 —— 对话卡死且无法恢复。这正是该分支存在的意义所要打断的那类循环，只是换了一个块类型。现在请求含文档时会一并剥离文档与图片；仅含图片的情况行为不变。

- **诊断信息中的主机名加上了长度上限**。上一版给 URL 路径设了 120 字符上限，主机名却没有 —— 病态的超长 baseUrl 仍会撑大错误消息。现在两端都有上限。

## 说明

- **LSP 在正式版默认关闭**：语言服务器能力由 `CLAUDE_CODE_LSP` 环境变量控制（开发模式默认开，正式版需设为 `1`/`true`/`yes`/`on`）。未开启时文件头的状态胶囊会显示「语言服务器不可用」，编辑与保存不受影响。
- 本次未改动任何用户界面。
