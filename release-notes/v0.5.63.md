# Code Council v0.5.63

> 本版本彻底修复"点击停止后台任务后重启 IDE 仍显示运行中"的问题。

## 重点更新

### 停止确认持久化
服务器确认任务已停止时，桌面端现在会把这条确认持久化到本地。此前停止标记只存在内存里——CLI 已死时 transcript 里永远不会写入终态通知，重启 IDE 后从 transcript 重建任务又会变回"运行中"。现在重启后会话恢复时自动应用这些记录，被停止的任务保持"已停止"状态。

同 ID 的新生命周期任务（停止后重新启动的同名任务）不受影响，仍正常运行。

### 附带修复
- 多会话切换时滚动条跳到最顶部的问题（切换前同步保存旧会话滚动位置，避免后台任务状态更新的竞态污染快照）
