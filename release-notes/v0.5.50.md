# Code Council v0.5.50

> 本版本修复 Electron Desktop 中工作区外图片附件无法预览和标注的问题，并保持原有本地文件访问安全边界。

## 修复

### 工作区外图片预览

- 修复通过“添加文件或图片”选择 `D:\download` 等工作区外目录中的 JPG、JPEG、PNG、GIF 或 WebP 后，预览请求被本地文件白名单拒绝并降级为普通文件卡的问题。
- 用户明确选择、粘贴或拖入的图片现在直接使用该 `File` 的已授权内容生成本地预览，不再依赖 `/api/filesystem/file` 读取工作区外路径。
- 静态图片预览继续经过现有压缩流程；GIF 为保留动画仍保持原格式，仅作为本地显示数据，不进入模型附件 payload。
- 单张图片读取或预览生成失败时只降级该附件，不再丢弃同一批次中的其他文件。

### 图片标注

- 恢复工作区外 JPG 的“标注图片”入口和图片标注弹窗。
- 新会话欢迎页 Composer 与活动会话 Composer 使用一致的图片选择、预览和标注行为。
- 保存标注后仍生成 PNG 附件，并清除原始文件路径，避免标注结果与原文件内容混淆。

### 停止重试

- 修复请求重试或流式降级期间点击 Stop 后，迟到的 `api_retry` / `streaming_fallback` 状态再次激活已结束会话的问题。
- Stop 后的旧回合重试状态会在 Server 与 Desktop 两层被丢弃；下一条真实用户消息仍可正常开始新回合。

### 后台任务收尾

- Agent 在结束对话前会核对自己启动但尚未收到终态通知的后台任务，避免已完成或失败的 watcher 长期显示为运行中。
- 已无用或明显失控的后台任务会主动停止；用户仍需要的开发服务器等常驻服务会继续保留，不因前台回合结束被一刀切清理。
- 用户点击 Stop 不会触发 Agent 重新检查或重启已经完成、失败的旧任务。

### 安全与兼容性

- 不放宽本地 Server 的文件系统白名单；未由用户选择的任意 `D:` 盘或工作区外文件仍无法通过预览 API 读取。
- Electron 附件继续保留真实本地 `path`，发送给模型的普通图片附件仍保持 path-only，不把预览用 Base64 写入 WebSocket payload。
- 非图片附件继续以路径附件处理，不额外读取或内联文件内容。

## 版本

- Electron Desktop：`0.5.50`
- 根 CLI 版本保持 `999.0.0-local`
