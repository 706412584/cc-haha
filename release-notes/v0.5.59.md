# Code Council v0.5.59

> 本版本修复 TaskUpdate 工具因缺少 import 导致崩溃、后台 Bash 任务无法停止且重启后仍显示运行中的问题。

## 重点更新

### Bug 修复

#### TaskUpdate 崩溃修复

- 修复 `TaskUpdate` 在任务列表完成时抛出 `ReferenceError: feature is not defined` 的问题。
- 根因：`src/tools/TaskUpdateTool/TaskUpdateTool.ts` 中使用 `feature('VERIFICATION_AGENT')` 和 `getFeatureValue_CACHED_MAY_BE_STALE()` 但遗漏了 import 语句。
- 影响范围：任何包含 3+ 个 task 的任务列表，在最后一个 task 被标记为 completed 时，TaskUpdate 调用会直接崩溃。

#### 后台 Bash 任务停止修复（三层防护）

- **Layer 1 — 停止按钮超时清理**：`stopBackgroundTask` 设置了 `stoppingBackgroundTaskIds` 防重复守卫，但无超时清理——WebSocket 消息丢失后，后续点击停止按钮被永久忽略。现添加 30 秒超时自动清理。
- **Layer 2 — 终端状态覆盖**：`mergeBackgroundAgentTaskRecords` 中，当已存在的任务状态为 `running` 但恢复的任务状态为 `killed/completed/failed` 时，即使时间戳较旧，终端状态也优先覆盖 running 状态，避免任务永久卡住。
- **Layer 3 — 过期任务自动清理**：会话恢复时，对 `startedAt` 超过 24 小时的 running 任务自动标记为 killed，因为进程早已死亡。
