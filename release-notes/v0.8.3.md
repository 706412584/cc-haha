# Claude Code Haha v0.8.3

v0.8.2 之后继续走查，重放**上游 v0.7.0 合并静默覆盖的插件页与 MCP 页 fork 定制**。全部对照合并前 fork 顶点（v0.7.13）逐项找回，视觉沿用新版 Porcelain 骨架，只补回功能逻辑。

## 插件设置页找回

上游整文件重写把 fork 的两块安装入口连同状态接线一起覆盖了，现已重放：

- **推荐插件区**：官方精选目录（Superpowers、GitHub、Linear、Figma、Playwright 等）网格展示，带分类徽章、本地化描述、一键安装与「已安装」态。接回 store 的 `fetchCatalog` / `installCatalogPlugin`。
- **URL 安装市场区**：粘贴 marketplace 源（git/URL）直接添加，回车即提交，接回 `addMarketplaceFromInput`。
- **零插件空态**：不再是提前 return 的整页空白——首次使用（零插件）时仍能看到推荐区与 URL 安装区，空态提示内联到已装列表位置，引导用户去装第一个插件。
- **插件详情页**：找回「配置」按钮与 `PluginConfigModal` 挂载（仅当插件声明了 `userConfig` 时出现）。

## MCP 设置页找回

- **市场入口 + 工具 tab**：列表头的「浏览市场」按钮、服务器详情/编辑页的「概览 / 工具」分段切换（`McpToolsTab` 列出并开关单个工具）全部补回；可编辑服务器的编辑页也重新挂上工具 tab。
- **会话热同步接线**：这是本轮关键一块。列表每行补回 **Refresh 按钮**（`handleRefresh` → `reconnectServer` 并把 `mcp_reconnect` 控制消息扇出到打开的会话），`handleToggle` / `handleSave` / `handleReconnect` 全部向 store 透传 `activeSessionId`，新增 `syncWarningDetail` 统一提示未能热注入的原因（无会话 / 未运行 / 不同项目 / 失败）。没有这层接线，新增或重连 MCP 服务器不会同步进正在运行的会话，需要重启才生效。
