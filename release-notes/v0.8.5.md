# Claude Code Haha v0.8.5

v0.8.4 发布后，对合并前 fork 顶点（v0.7.13）做了一次**函数级全量差异扫描**（提取 1172 个函数逐一比对），发现 9 个函数在合并时丢失。其中 8 个已随 v0.8.4 恢复（`useEdgeAutoExpanded`、`slimOversizedEntry`、`HISTORY_RETAINED_RECORD_BYTES`、`truncateAgentPreview`、`extractMediaAgentImages`、`extractSiblingLocalPaths`、`LanguageServersSection`、`proxyStepLabel`），本版补上最后一个。

## 补齐项

- **检查点预览预算守卫**（MessageList）：`isTurnChangeCardsUnavailable`（fork d26d9c52）。服务端对超大 transcript 拒绝构建逐轮变更卡片是**刻意的预算限制**，不是故障——卡片缺席本身已经说明了情况，再弹一条原始英文横幅只是噪音。恢复后，该错误在加载失败路径不再显示横幅，真实加载失败仍然正常上报。
