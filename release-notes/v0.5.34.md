# v0.5.34

> 这一版修复压缩上下文后继续会话时，历史图片内容可能重新进入模型请求并触发图片类型 API 400 的问题。

## 重点更新

- **压缩上下文后继续会话更稳定**：修复 compact summary 的 prompt-cache-sharing 路径没有清理历史图片块的问题，避免旧上下文里的无效 base64 图片再次进入模型请求。
- **图片内容清理覆盖更完整**：compact summary 请求现在会同时清理用户消息里的直接 `image` block，以及 `tool_result.content` 中嵌套的图片 block。
- **compact 两条请求路径行为一致**：prompt-cache-sharing 路径和 fallback streaming 路径现在共用同一套 compact 上下文清理逻辑，避免不同路径表现不一致。
- **后台进程回收更可靠**：Windows 桌面端停止/清理会话时会终止完整 CLI 进程树，避免旧会话留下 `cmd` / `npx` / `node` / `python` / MCP server 等子进程继续占用资源。
- **保留 compact 边界语义**：压缩摘要仍只基于最新 compact boundary 之后的消息生成，不会重新摘要更早的历史内容。

## 验证
