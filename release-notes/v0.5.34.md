# v0.5.34

> 这一版集中修复长会话稳定性、后台资源回收、消息渲染可靠性，并加入全局护眼浅绿主题与移动 H5 体验优化。

## 重点更新

### 长会话与 compact 稳定性

- **压缩上下文后继续会话更稳定**：修复 compact summary 的 prompt-cache-sharing 路径没有清理历史图片块的问题，避免旧上下文里的无效 base64 图片再次进入模型请求并触发图片类型 API 400。
- **图片内容清理覆盖更完整**：compact summary 请求现在会同时清理用户消息里的直接 `image` block，以及 `tool_result.content` 中嵌套的图片 block。
- **compact 两条请求路径行为一致**：prompt-cache-sharing 路径和 fallback streaming 路径现在共用同一套 compact 上下文清理逻辑，避免不同路径表现不一致。
- **保留 compact 边界语义**：压缩摘要仍只基于最新 compact boundary 之后的消息生成，不会重新摘要更早的历史内容。

### 桌面端稳定性与资源回收

- **后台进程回收更可靠**：Windows 桌面端停止/清理会话时会终止完整 CLI 进程树，避免旧会话留下 `cmd` / `npx` / `node` / `python` / MCP server 等子进程继续占用资源。
- **长服务与 MCP 子进程残留减少**：会话关闭、停止和等待退出路径统一走完整进程树清理，降低后台服务越开越多的问题。

### 消息渲染与自动滚动

- **修复长对话自动滚动吞消息**：虚拟化消息列表现在会把内联 `tool_result` 的内容长度纳入 `tool_group` 高度估算，避免自动滚动到底部时高度模型偏小导致消息或工具结果没有挂载显示。
- **工具调用组高度缓存更准确**：`tool_group` 的 metric signature 会包含对应 tool result 内容变化，长输出工具结果追加时能触发正确的虚拟窗口更新。

### 外观主题

- **新增护眼浅绿主题**：外观设置新增 `护眼浅绿 / Eye-care Green`，可在纯白、经典暖色、护眼浅绿、暗色和跟随系统之间切换。
- **护眼主题全局化**：护眼浅绿不只是侧边栏变绿，主背景、内容区、卡片、输入框、hover、选中态、边框、代码块和 diff 标题都统一为低饱和浅薄荷绿色系。
- **主题状态持久化与切换完整**：`eyeCare` 已加入主题白名单和 `toggleTheme()` 顺序，应用重启后可正确恢复。

### 移动 H5 / Android 本地运行验证

- **移动 H5 布局更适配触屏**：移动端设置页、侧边栏、顶部栏和输入区的触控尺寸与滚动布局更适合手机 WebView 使用。
- **桌面与移动体验隔离**：移动 H5 专用样式通过移动状态和触屏标记生效，避免影响桌面布局。
- **Android/Termux 本地运行验证继续推进**：补充黑鲨 SKW-A0 设备验证记录，扩展 Node server slice 的请求探测与回退链路验证。

### 版本与打包

- **桌面包版本对齐 0.5.34**：`desktop/package.json` 已更新到 `0.5.34`，Windows 安装包和 update metadata 会生成 `Claude-Code-Haha-0.5.34-win-x64.exe`。
