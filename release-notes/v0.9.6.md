# v0.9.6 — 2026-11-25

## 中转会话限制兼容

- 星驰 relay 的 `session_turn_limit_exceeded` 现在自适应处理：识别“已满 20 轮对话”和“模型已回复超过 100/200 轮”两类文案；体积口径按 250KB 模型可见文本（UTF-8，含 base64 媒体）预算裁剪，保留最新工具调用/结果、任务锚点和早期用户指令。
- 窗口外的工具活动压缩为 `Compacted earlier activity` 摘要（工具名/参数/结果前 500 字符，≤32KB），不再整段丢弃；早期用户指令最多保留 64 条/16KB，并过滤 task-notification、skill、local-command 等系统注入。
- 最新单条消息带超大截图时把媒体降级为占位，而不是丢弃整轮；窗口内 `tool_use`/`tool_result` 双向完全配对。
- 裁剪预算可配置：provider 的 `turnLimitTrimBytes` > settings.json 的 `env.CLAUDE_PROXY_TURN_LIMIT_BUDGET_BYTES` > 进程环境变量 > 默认 250KB。

## 修复

- Settings JSON 自动回填密钥时跳过 `proxy-managed` / `dummy` 占位符，避免保存时用 CLI 占位符覆盖 provider 真实 key。
- 会话恢复中断通知明确“主会话与工作区可用”，避免模型把重启导致的子任务中断误判为环境暂停。
- media-gen 配置保存后会刷新活跃会话的插件/MCP 状态。

## 已知限制

- media-gen 的插件 MCP 环境在 CLI 启动时装配。本版本保存配置后会刷新插件状态，但已连接的 media-gen 进程可能仍需新开会话（或重启应用）才会拿到新的 provider 列表。
- 星驰 provider（讯飞网关 `loomy`）账号当前不支持图片生成，media-gen 会返回“当前账号暂不支持图片生成”。
