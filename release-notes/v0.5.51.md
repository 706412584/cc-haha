# Code Council v0.5.51

> 本版本修复新会话首次请求的推理强度配置，以及 Agent 已完成但界面仍显示“进行中”的终态通知竞态。

## 修复

### 新会话推理强度

- 新会话发送第一条消息前，会将界面当前显示的推理强度写入 runtime config，避免界面显示“最大”但首次请求仍按 High 发送。
- 优先使用模型声明的默认推理强度，并为 OpenAI、Grok 和自定义 Provider 保留正确的默认模型回退。
- 模型明确不支持 reasoning effort 时不再发送无效的 effort 配置。

### Agent 完成通知

- Agent 完成后，在父会话确认收到终态通知前不再提前回收任务，避免已完成的 Agent 长期显示为“进行中”。
- 延迟任务回收会基于最新状态再次检查未确认通知，避免长回合和异步轮询之间的竞态。
- 兼容旧版本遗留的持久化 completion inbox：即使任务已被旧 runtime 回收，仍可继续投递并确认已有完成通知。
- 保留 Agent resume 的 epoch 隔离，过期完成通知不会误投递到新的 Agent 生命周期。
