# Claude Code Haha v0.8.1

修复 v0.8.0（上游 v0.7.0 大合并）中**被静默丢掉的四处 fork 细节**。全部是合并冲突解决时上游骨架替换了 fork 实现、且测试没能兜住的类型——本次实机走查发现后逐一找回。

## 图标变英文（Material Symbols 类规则丢失）

会话卡片、设置侧栏、任务横幅里出现 `checklist`、`dns`、`expand_less` 这类原始英文单词，个别还随 loading 动画整体旋转出镜像效果。根因：合并换用新样式表时，把图标字体和 `<span class="material-symbols-outlined">` 之间的**类绑定规则**弄丢了——字体文件还在、组件还在用类名，但没有任何规则告诉浏览器"这个类用这个字体"。现按原实现补回（含 `@layer base` 的字号层级，保证 `text-[14px]` 等工具类仍能覆盖默认 24px）。

## 图片标注入口丢失

- **会话内输入框**：附件缩略图上的"标注"按钮（画笔角标）随工具栏重建消失，图片标注弹窗（涂鸦/箭头/文字）在会话里完全打不开——只有新建会话首屏还留着入口。现已找回：保存后以 `-annotated.png` 回写附件，与首屏行为一致。
- **入口按钮本体**：共享附件组件上的画笔角标一并恢复。

## 品牌字标回退

侧栏字标被合并改写成上游的「cc-haha」、GitHub 链接指回上游仓库。已按项目规则改回 **Code Council** + fork 仓库地址，字标测试同步更新断言，防止下次合并再静默漂移。

## 测试基建

合并丢弃了 ChatInput 测试的 imageCompress mock：jsdom 不解码图片，真实压缩器的 `img.onload` 永不触发，粘贴图片的异步测试超时。恢复为直通 mock。顺带移除了指向已删 CSS 规则的 `data-capability-menu-open` 死标记（新版 H5 外壳已无那条滚动裁剪容器）。

## 验证

- desktop `tsc`：0 错误。
- ChatInput 114、Sidebar 104（含新字标断言）全绿。
- 独立子代理对照合并前 fork 顶点逐项核对 40+ fork 特性：除上述四项外，编排开关、编排提示词、项目规则、独立 Trace 页、隧道 UI、团队 resume/outcomes、假 tool_use 检测、中转重试策略等全部确认存活。
