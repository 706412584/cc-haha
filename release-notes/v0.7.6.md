# Claude Code Haha v0.7.6

本次合并上游 **Claude Code v0.6.8**（47 个提交，444 个文件），带来**本地语音听写**、**工作区文档预览**、**精选技能目录**、**等待处理的会话高亮**与**按格式的文件图标**；合并过程中有 8 处 fork 定制被静默覆盖（无冲突、无类型错误），已全部找回或按语义统一。

## 上游 v0.6.8：语音、文档预览与技能市场

- **本地语音听写**：输入框旁的麦克风按钮，录音后由本机识别进程转写（16 kHz 单声道），文字进草稿不自动发送；「设置 → 语音输入」可开关、选语言和麦克风。识别引擎运行时下载到本地并校验哈希，支持断点续传与国内镜像。
- **工作区文档预览**：Agent 写出的 PDF、Word、Excel 直接在工作区侧边打开，支持缩放、按文件记住滚动位置，文件被改写后自动刷新；聊天里提到的本地图片（工作目录外、`~`、`C:\`、`file://`）直接显示，工具返回的图片以缩略图出现在调用下方。
- **精选技能目录**：技能市场默认打开内置精选目录（398 个技能、13 个分类），不再每次实时请求注册表；详情页补齐统计、安全报告与更新日志，未审计技能需确认后安装。
- **等待处理的会话高亮**：会话产出需要你决策的卡片时，顶部选项卡和侧边栏显示醒目标记。
- **按格式的文件图标**：生成的文件卡片、回合改动卡片和消息附件按扩展名显示带颜色和角标的图标。
- **模型**：Claude Sonnet 5.5（`claude-sonnet-5-5`，1M 上下文）、GPT-6.1-Sol（桌面端与 Codex OAuth）、Grok 报 HTTP 426 的修复。
- **稳定性**：「停止并关闭」不再留下后台任务；请求过大（413）报出实际体积并自动把这次请求携带的图片与文档替换为占位符，下一条消息即可继续；后台任务完成后的模型回复不再被吞；单条过大 transcript 不再让整个索引降级。

## 合并中丢失的 fork 定制点：已找回

合并把部分文件整体取用了上游版本，fork 在这些文件里的增量改动随之消失。这类丢失不产生类型错误、不影响编译，**只有对应测试或人工比对才会暴露**。本次找回：

- **`ModelSelector` 的三处调用点退化**（独立审核代理发现）。`pendingRuntimeSelection` 从回退链消失、`resolveDefaultRuntimeSelection` 参数退回上游形式、`getProviderModelCapabilityOverride` 不再传 preset 的 `defaultModels`——三处 helper 都还在，只有调用点没了。已回植。
- **本地索引的按 transcript 失败隔离**。fork 版在单条 transcript 缺 locator page 或校验失败时让**整个索引**进入冷却；上游把这类失败限定在该 transcript 内。已取上游版。
- **媒体剥离窗口的统一**。这是一处**真正的语义分歧**：上游在最近一条用户消息处停止剥离；fork v0.5.50 刻意改成「剥离所有更早的候选」，因为并行工具结果表现为连续多条 user 消息，停在最近一条（常是纯文本 tool_result）会把坏图留在历史里，之后每条消息都失败。两侧各有一个回归测试断言相反的行为。最终实现取**两者的交集**：窗口 = 「最后一条 assistant 消息之后」——它对应的请求已成功，证明更早的媒体被接受，必须原样重放；窗口内则剥掉每一条带目标媒体的 user 消息，跳过无媒体消息与合成错误。两侧测试全部通过。
- **通知抑制语义改为上游 #1389**：只隐藏那条排队的通知记录，不再用抑制状态机——fork 的规则仍会吃掉一条纯文字的实质回复。这是**有意的行为分歧**，已在 PR 中记录。
- **`ToolCallBlock` 双渲染**：上游 `ToolResultImages` 与 fork 的 `ImageBlockGallery` 并存导致每张工具图片渲染两次，已移除后者。
- **`sessionHistoryRecovery`**：取上游的证据分类实现，回植 fork 的 `slimToolUseResult`（剥离 `originalFile` 快照，避免工作区证据顶过预算返回 413）。
- **`TabBar` chevron 契约**：恢复 fork 的「两个槽位始终挂载」（`disabled` + `invisible`，而非卸载）。
- **`fflate` 重复依赖**：合并把它同时放进 dependencies，会打进 app.asar；已删。
