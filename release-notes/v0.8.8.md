# Claude Code Haha v0.8.8

合并上游 NanmiCoder/cc-haha **v0.7.5**（v0.7.1..v0.7.5 共 241 个提交，未合并 68 个）。本版以 fork 为基底吸收上游：模型委派、Token 用量重构、lean profile、工作区文档标注、许可证变更等；60 个冲突文件（120 个冲突块）逐文件解决，fork 定制逐项验证存活。

## 上游带来的新东西

- **跨会话模型委派**（#1626 / #1628 / #1629 / #1631）：会话可把子任务交给另一个会话执行，被委派的会话在活动面板有独立区块，标题在无页面打开时也保留。

- **lean profile**（#1613 / #1619）：实验性的精简 agent 配置，桌面端可切换，压缩系统提示词与工具集。
- **工作区文档标注**（#1608）：Word / PDF / 电子表格可直接标注。
- **Windows 迁移权限预检**（#1620）：数据目录迁移前先检查权限，避免迁到一半失败。
- **OpenCode Go Gemini 路由**（#1630）：Google `generateContent` 格式接入。
- **许可证变更**（#1575 / #1576）：切换为 Community Source License 1.0，跟随上游。
- 其它：+ 菜单一级化（#1601）、项目选择器不越界（#1609）、原生全屏与 F11（#1606）、Linux node-pty 可加载（#1602）、流内错误按失败请求重试（#1600）、Windows 控制台闪烁修复（#1585 / #1593）、等待会话徽标（#1534）。

## 合并后修复

- **`agentProfile` 列表水合丢失**：上游把 `agentProfile` 加进 `compareSessionLists` 的字段集合，但 fork 的 `hydrateIndexedSessionForList` 未透传，导致索引侧会话条目永远缺少该字段，shadow 模式每次比较都判为不一致。已补 `agentProfile` 与 `openAIFastMode`。
- **用户 Stop 被当成结束团队**：`stopTeamPlanRuntimesForParent({ pauseReleased: true })` 会跳过停止运行中的 launch，但仍落进 `8c9bbcf8a` 为「结束团队」加的 `running` 分支，于是暂停被记成 `interrupted`。现在暂停的 launch 保留 `running`。
- **成员成功回合残留上次失败**：启动路径额外注册了一个 `onOutput` 处理器，用早于 `handleWorkerResult` 的快照整文件覆盖团队文件，把刚清掉的 `lastError` / `autoRetry` 写回去。`handleWorkerResult` 已负责成员状态，该处理器已删除（同时也消掉了重复的 idle 通知）。
- **三处融合缺陷**：`useKeyboardShortcuts` 的死引用、`providerRuntimeEnv` 丢失的 DeepSeek Account 分支、`dataMigration` 终态短路后未保留 journal。
- **两处会话缓存字段**：`sessionService` 丢失的 `uiFileHistoryReads` / `inspectionSnapshots` 声明。
- **localIndex schema**：fork 列（`is_team_worker` = v7、`openai_fast_mode` = v8）与上游 `agent_profile` 落 v9；`hasColumn` 幂等守卫。
