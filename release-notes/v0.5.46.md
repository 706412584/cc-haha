# Claude Code Haha v0.5.46

> 本版本修复跨 Provider 会话恢复、后台 Agent completion 交付、会话路径、Windows Workspace LSP、多图 replay 与编辑器高亮主题的一致性问题；收敛会话正文索引的内存行为；补齐 Grok 断流重试；并合并上游 `v0.4.11` 桌面体验与 Agent 工作流能力（保留本地产品定制）。

## Highlights

- **跨 Provider 安全切换**：有历史的会话不再用原 UUID 恢复到不同 Provider；服务端先返回两阶段切换结果，确认后创建空白且幂等的新会话，源 transcript 保持不变。
- **Agent completion 不再静默丢失**：completion ownership 持久保留到真实 consumer 接收；queue cleanup、background handoff 与恢复路径会回滚并重投未消费通知。
- **多图 replay 稳定去重**：图片路径、文件名、随机上传前缀和顺序变化均按一对一身份匹配；真正不同的图片仍保留独立消息。
- **会话路径恢复**：filesystem fallback、degraded/indexed list 与 detail 都返回真实 canonical JSONL 路径。
- **Windows Workspace LSP 可启动**：从 npm package metadata 解析并验证 JS bin，避免裸命令和 `.cmd` spawn；unsupported、缺 prerequisite 和生命周期失败拥有独立 reason。
- **CodeMirror 高亮与主题**：编辑器使用 CSS-variable syntax HighlightStyle/theme，切换 light/dark/eyeCare 不重建 EditorView 或丢失 buffer/selection/undo。
- **会话正文索引止血**：启动不再自动全量重建正文索引；侧边栏刷新触发 `POST /api/sessions/sync-indexes` 手动同步；设置-通用提供「会话正文搜索」开关，关闭后停止 search coordinator、搜索 API 返回 409，并隐藏 Search chats / ⌘K（标题过滤保留）；单会话源超过 256 MiB 时跳过并标记 too-large。
- **Grok / OpenAI 兼容断流可重试**：`OpenAI messages stream disconnected before completion`（`api_error`）纳入流式重试；重试中对用户透明，耗尽后仍以可见 API 错误呈现。
- **Desktop 版本**：Electron Desktop 权威版本更新为 `0.5.46`；根 CLI 版本保持 `999.0.0-local`。

## 上游 `v0.4.11` 合入（具体更新）

合并来源：`upstream` 标签 `v0.4.11`（NanmiCoder/cc-haha）。策略：保留本地产品行为（Code Council 品牌、H5 访问、Office 可视化、in-session Provider 切换等），吸收上游客观 bug 修复与桌面新能力。

### 新增能力

- **互动桌面宠物**：Electron 原生透明悬浮窗口；内置搭搭 / 弧弧 / 补补 / 回回；按工作中、等待处理、失败、空闲切换动作；可展开活跃任务并点击返回对应会话；支持拖动、点击互动、视线跟随、右键关闭与位置恢复。
- **本地自定义宠物**：支持导入透明 PNG / WebP 轻动画，以及 `1536×2288` v2 逐帧图集；可调尺寸、动画与任务面板；导入全本地完成，不调用当前聊天模型。
- **完整桌面 Agent 管理**：设置页浏览内置 / 用户 / 项目 / 插件 / 策略等来源与覆盖关系；创建、编辑、删除用户级与项目级 Agent（`AgentManager` 替换旧内联 Agents 面板）。
- **逐 Agent 模型与 effort**：每个自定义 Agent 可独立继承或指定模型（含 Fable / Opus / Sonnet / Haiku / 自定义 ID）、`low`–`max` 思考强度与可用工具；接入定义、运行、恢复与团队执行链路（#1062）。
- **Claude 官方模型阵容更新**：识别 Fable 5、Opus 4.8、Sonnet 5、Haiku 4.5；补齐显示名、1M 上下文、推理强度与 Provider 环境映射（实际可用性仍取决于账号与 Provider）。
- **任务与 SubAgent 可观察性**：运行中 SubAgent 可立即打开详情并持续刷新工具记录（#1077）；Task V2 完成状态、并发更新与临时轮询失败更稳定（#1075）。
- **Kimi Code 预设升级为 K3**：Coding API、`k3`、262K 上下文、API Key 鉴权；补齐 required thinking / effort / max effort。
- **Renderer lifecycle / 宠物 IPC / 打包守卫**：主进程 renderer 生命周期、pet-preload、sidecar 与 electron 输出空闲检查等上游加固一并合入。

- Provider 空 / 全零 usage 时保留上下文估算，回退本地 transcript，不误作费用（#1063）。
- 首轮附件消息服务端回放去重；兼容 Windows 路径、UUID 前缀上传与内联图片（#1069）。
- 拒绝工具权限后的正常中断不再误报执行失败（#1070）。
- 任务完成状态及时更新；防止旧请求覆盖新状态与轮询失败闪空（#1075）。
- 运行中 SubAgent 详情不再长期停在「开始中」（#1077）。
- Provider 预设接口暂不可用时仍可「添加服务商」；常用预设桌面内置（#1078）。
- Windows 白屏 / Renderer 异常退出 / 代理重置 / 终端与 IM WebSocket 生命周期恢复与错误隔离（#1064, #1065, #1071）。

- Agent 保存后热重载不再错误阻塞；嵌套 Git 仓库时项目 Agent 写入路径与刷新竞态修复。
- Windows 长空闲后本地 HTTP 连接复用超时与请求取消 / 任务轮询资源清理。

## 发布注意

- `v0.5.45` tag 和正式 Release 保持不可变；本次仅由 merged `main` 的 `Release Desktop` workflow 创建 `v0.5.46` draft。
- 正式资产必须与记录的 merge SHA、workflow `headSha` 和 package smoke 结果一致。
- 异常超大 transcript 可能导致旧版正文索引内存暴涨；本版默认不在启动时重建，并支持关闭正文搜索。若仍异常，可删除对应会话 JSONL / 索引库后重试。
- 桌面宠物为 Electron 功能，不在 H5 中运行；单图导入为本地轻动画，非 AI 逐帧生成。
- Agent effort 是否完整生效取决于所选模型与 Provider；不支持的组合可能被降低或忽略。
