# Claude Code Haha v0.5.45

> 本版本修复全文搜索索引失控增长与重建期间阻塞本地 sidecar 的问题。

## Highlights

- **全文索引实际容量上限**：`CC_HAHA_SEARCH_INDEX_LIMIT_MB` 现在通过 SQLite `max_page_count`、小批事务和 WAL checkpoint 形成真实物理约束，不再只是写入完成后的告警。
- **启动时自动清理超限索引**：打开数据库前统计 `search-index-v1.sqlite`、`-wal`、`-shm`、`-journal`；总量超过配置上限时自动删除整个 disposable family 并从空库受限重建。删除或重开失败时 fail closed，不启动 watcher。
- **分批写入与删除**：大型 source 的 document insert、旧 document delete 和 stale source cleanup 均拆成有界事务；每批 checkpoint 后让出事件循环，避免全文索引重建阻塞 `/health`、inspection、task list 等本地 API。
- **容量命中立即停止 sweep**：full sweep 会中止当前 discovery，targeted sweep 会停止后续 path，不再继续读取和投影无用 source。
- **中断恢复一致性**：投影期间 source 保持 `pending`，查询不会暴露半成品；下次 sweep 对非 `ready` source 从 byte 0 重建并先清理旧文档，避免重复或永久卡住。
- **独立关闭全文索引**：新增 `CC_HAHA_SEARCH_INDEX=off`。关闭时仍可保留 session metadata index，但不会启动全文 search coordinator，也不会打开、删除、创建或重建 search DB family。unset、`on` 或非法值保持默认启用。
- **后台任务停止静默幂等**：停止时如果 CLI session 已经退出，服务端返回不可见的 stopped 确认，不再显示 `CLI session is not running` 错误；前端立即清除停止中标记并让任务离开“关注中”，其他真实停止失败仍按原流程提示。
- **Desktop 版本**：Electron Desktop 权威版本更新为 `0.5.45`；根 CLI 版本保持 `999.0.0-local`。
