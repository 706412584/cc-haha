# Claude Code Haha v0.5.41

> 本版本吸收上游 Claude Code Haha `v0.4.10`，修复 Local Index 会话列表缺失 transcript 文件路径的问题，并完善会话恢复、后台任务终态、对话浏览、H5 清理和 Windows 覆盖升级体验。

本说明面向 `v0.5.41` 最终用户与发布维护者。正式安装包从最终 reviewed merge SHA 构建，并通过 package smoke、冷启动和真实会话文件路径验收后发布。

## Highlights

- **会话文件操作恢复**：Local Index 会话列表现在会返回真实 `.jsonl` transcript 路径，“复制文件路径”和“在文件夹中显示”不再统一提示“无法获取会话文件路径”。
- **会话 restart 与 checkpoint 恢复**：重启运行时前保存当前上下文，恢复已有会话时避免不必要的预热，并改进 checkpoint 回退后的状态恢复。
- **后台 Agent 终态持久化**：后台任务完成、失败或停止通知会写入会话记录，刷新或重新进入会话后仍能恢复结果。
- **对话搜索与滚动恢复**：支持在长对话中搜索；离开并重新进入会话时恢复用户主动滚动的位置，同时保留新消息自动跟随语义。
- **H5 断连清理**：连接关闭后清理延迟到达的 permission 请求和相关状态，避免失效请求残留。
- **Windows 覆盖升级加固**：安装程序更可靠地识别运行中的旧进程、恢复旧版安装数据，并降低覆盖安装失败或数据错位的概率。
- **系统代理恢复更稳健**：动态系统代理配置在异常或退出路径中能够正确 reset，减少代理状态残留。
- **诊断内存有界**：SDK diagnostics 对单条消息和累计捕获量设置上限，避免异常大消息持续占用内存。
- **Renderer 启动失败可见**：Desktop Renderer 初始化失败时提供明确错误界面，不再只显示空白窗口。
- **Native Preview 跟随缩放**：原生预览区域随应用 UI zoom 更新边界，减少缩放后的错位。

## 会话文件路径修复

`v0.5.40` 的 Local Index hydration 已能快速返回历史会话，但 indexed session projection 漏掉了 `filePath`。会话本身和 transcript 文件仍然存在，Renderer 却无法执行依赖该字段的菜单操作。

`v0.5.41` 在 indexed list 和完整 indexed hydration 中统一映射：

```text
filePath = transcriptPath
```

因此：

- “复制文件路径”会复制真实 `.jsonl` 绝对路径。
- “在文件夹中显示”会定位真实 transcript 文件。
- 继续保留现有 transcript 路径安全验证。
- workspace 已删除或不可达时，历史列表仍按 `v0.5.40` 的有界探测及时返回。

## Windows 与测试隔离

- Windows 深层 sandbox fixture 中的 Git 测试使用**测试子进程级** `core.longpaths=true`。
- 不修改用户全局 Git 配置。
- 不创建或依赖 `SUBST` 虚拟盘。
- `R:` 虚拟盘不是产品运行或测试要求，发布验收确认其不存在。
- 临时 workspace 清理由已有 retry helper 处理 Windows 文件句柄短暂占用。
