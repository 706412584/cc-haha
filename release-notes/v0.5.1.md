# Claude Code Haha v0.5.1

这是 `v0.5.0` 之后的体验与稳定性更新，重点补齐 Provider 导入、聊天内容导航、后台任务与重连可靠性，并继续收紧本地运行边界。

## 新增与改进

- 支持从 cc-switch 一键导入 Claude Code Provider，并从 OpenAI 兼容接口获取模型列表。
- 模型目录改为缓存优先、后台刷新，Provider 不可达时不再阻塞桌面端启动。
- Slash 命令按用途分组；运行位置选择、发送按钮、会话标签和设置侧栏交互进一步简化。
- 回复中的 URL 和文件路径可直接点击；Shell 工具卡会显示输出，完成的对话会显示结束时间与耗时（#1145、#1146、#1149、#1151）。
- 新增 AskUserQuestion 的“再聊一下”入口，并自动识别、记住系统显示语言（#1121）。
- 完善 Telegram 的会话恢复、Provider / 模型切换、Skills 调用、权限确认和图片回传（#1130）。
- Linux Release 新增 x64 / ARM64 RPM 安装包；项目许可证更新为 MIT。

## 修复

- 修复桌面端重连后重复回放旧 CLI 消息的问题。
- 修复 Windows 无法创建符号链接时后台 Agent 输出为空，以及工具路径显示过长的问题（#1018、#1141）。
- 修复项目级 MCP Server 重启后消失、IM 设置保存空绑定字段的问题（#1126、#1137）。
- 修复图片消息顺序错乱，以及 OpenAI Responses 转换丢失工具返回图片的问题（#1053、#1095）。
- 修复元素选择确认失效、WebView 轻微尺寸抖动、宠物任务面板碰到 macOS 菜单栏等桌面问题（#1140、#1144）。
- 修复长会话处理性能、CLI 部分输出与恢复流程中的多项稳定性问题（#1100）。
- 加强本地文件、预览、H5 访问和远程图片请求的安全边界，同时恢复受影响的正常功能。

## 安装

请在本页面底部 Assets 中下载对应平台和架构的安装包：

- macOS：`Claude-Code-Haha-0.5.1-mac-arm64.dmg` / `Claude-Code-Haha-0.5.1-mac-x64.dmg`
- Windows：`Claude-Code-Haha-0.5.1-win-x64.exe` / `Claude-Code-Haha-0.5.1-win-arm64.exe`
- Linux x64：AppImage、deb 或 `Claude-Code-Haha-0.5.1-linux-x86_64.rpm`
- Linux ARM64：AppImage、deb 或 `Claude-Code-Haha-0.5.1-linux-aarch64.rpm`
