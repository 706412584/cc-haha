# Code Council v0.9.2

合并上游 v0.7.9，并保留 Code Council 的 Provider、中转韧性、团队、H5 隧道与桌面定制。当前为本地验证版本，远程发布等待本地 Windows 包验证通过。

## 上游新增

- 团队运行控制：暂停/恢复团队与主任务，暂停时调整成员模型，恢复失败可重试。
- Claude 官方订阅用量、应用图标角标、会话复制/导出 Markdown。
- 深灰主题、可拖动的工作区预览分隔条、输出 token 额度升级开关。
- 大图请求压缩与共享内联预算，历史预览仍使用原图。
- Provider 并发保存与环境隔离、计划评审模型切换、即时停止、后台通知归入活动面板、Git/worktree 元数据、MCP 代理与 H5 路径规范化修复。
- 手机客户端升级至 0.1.5，改进推送错误分类与通道切换反馈。

## fork 合并修复

- 保留 UA 跨协议透传与自定义请求头，并修复清空请求头后托管环境仍残留旧值。
- 停止计时器同时检查进程身份与前台回合代际，防止误杀切模型后的新进程或自主续跑的新回合。
- 恢复四套经典主题 CSS，与上游深灰主题共存；Agent Office 同步适配深灰主题。
- Provider 索引从快照恢复时先恢复 active provider 身份，再迁移 settings owner，避免显式子代理模型配置丢失。
- 修复团队中断计划跨服务端重启后被 runtime-control 暂停门禁挡住的问题；已撤销的恢复和普通暂停团队追加成员仍会被拒绝。
- 保留会话列表水合并发、inspection 增量折叠、12 MiB 历史保留上限、JSONL 导出、图片标注和主系统提示词替换。

## fork 新增

- **中转会话 ID 轮换**（`fdec0f3da`）：按会话计数的中转（如 OpenCode Zen Go，100 次上限）打满后返回 `400 session_request_limit_exceeded`，同一会话连 `/compact` 都被拒，只能导出重开。现在 proxy 检测到该错误后自动把发给上游的会话 ID 轮换为 `原ID-r<n>` 并重试一次，对话原地续跑、CLI 无感。触发有三重门槛（仅 upstreamHeaders 模板含 `$SESSION_ID` 的 preset、恰为 400、body 含精确错误码），无关 400 不受影响；轮换 ID 成功过则计满后继续轮换，从未成功就被拒则永久禁用该会话的轮换（说明该中转按账号计数，避免每请求双倍流量）；本地 trace 与 prompt cache 路由始终用原 ID；状态带 6 小时 TTL、每会话 25 次轮换上限。`docs/FORK_CUSTOMIZATIONS.md` D 节已登记，防上游合并回归。
- **大会话历史完整浏览**（`0b0c58091` 及本轮补强）：普通打开默认加载最近约 500 条（真实 43 MB 会话实测 314 ms 首屏）；滚动到顶部自动补页（一次一个请求，不连读）；新增「加载全部 / 取消」，想看完整会话一键到底；头部计数改为「已加载 N 条」，不再把局部数量当总数。修复两类空白：最近几页全是空输出/后台唤醒记录时自动跨过不可见尾页继续补到可见对话；分页响应中剥除 thinking 的 `signature` 鉴权包裹字节，避免其挤占页预算。移动端 /m/ 同步获得滚动自动补页与加载全部；修复 H5 上 Spinner/HaloDot 循环动画停转（`useNativeDriver` 在 web 关闭）；500 条补页的 tool 配对从每页全量重扫改为 Map 索引。原始 JSONL 全程只读，不迁移、不截断、不去重。
