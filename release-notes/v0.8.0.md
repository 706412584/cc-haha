# Claude Code Haha v0.8.0

合并上游 NanmiCoder/cc-haha **v0.7.0**（144 个提交）：桌面端整体换装「素 Porcelain」视觉系统、新增数据迁移子系统、H5 手机/平板外壳重建、输入框 + 菜单重组。本版本是 fork 迄今最大的一次上游合并，解决 84 个冲突，全部 fork 特性逐一嫁接回新版骨架。

## 上游带来的新东西

- **Porcelain 视觉系统**：六套主题统一圆角/字号尺度，设置页改为 rail + paper 骨架，聊天改为气泡 + 工具时间线，输入框换成悬浮卡片。
- **数据迁移**：仓库目录搬家时自动迁移会话、配置与索引，过程中业务流量与索引写入暂停，完成后恢复；Windows 上对发布锁做了重试。
- **H5 手机/平板外壳**：触摸优先重做，+ 菜单在手机上是底部抽屉（sheet），44px 触控目标。
- **编排菜单重组**：+ 菜单围绕技能、连接器、运行模式重新分组；技能可一键安装（带安全扫描徽标）；Computer Use 合并进菜单开关。
- **后台任务收敛**：Stop 会连同后台 shell 任务一起收尾；被遗忘的 run_in_background 循环有了 31 分钟的断连回收上限。
- **轨迹（trajectory）内嵌**：会话内直接查看每轮的模型调用、工具与上下文注入。

## fork 特性全部保留（逐项嫁接回上游骨架）

- **品牌**：Code Council 文案、README、关于页。
- **中转韧性**：`describeUpstreamFailure` 诊断（连接错误带 code/errno/实际端点 URL）、transient 重试默认 4 次 + 60s 时间预算、thinking passthrough（`roundTripReasoningContent` 无条件透传，generic 模型不丢思考）。
- **编排模式**：+ 菜单里的编排/Solo/逆向编排三个开关照旧；设置里的编排提示词自定义、项目规则、独立 Trace 页三个 tab 保留。
- **H5**：cloudflared/Pinggy 隧道 UI 保留；上一版修的「+ 菜单被工具栏裁剪成灰块」随新 sheet 形态自然解决。
- **其它**：图片标注、假 tool_use 泄漏检测（cleanContent）、团队 strip 显隐、Adaptive thinking → enabled 改写（u2-flash 类网关不再 400）。

## 顺手修的

- 本地全量跑 `bun test src/server` 时 1700+ 连锁失败：三个测试文件顶层的 `mock.module('fs/promises')` 跨文件泄漏且无法注销，现于 `afterAll` 恢复真实模块。
- 五个语言的 trace 相关文案补齐 100 条/语言；经典四配色（Classic White/Light/Eye Care/Classic Dark）回归。
- 合并时被静默删除的 22 个 fork 文件（trace 视图组件、overlayStore、Material 字体等）全部找回。
