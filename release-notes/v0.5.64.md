主要吸收项：

- Tool Search opt-in 机制（默认关闭 + HTTP 400 兼容性警告），本 fork 仍隐藏 provider 表单里的开关
- Turn checkpoints、断线期间空闲 turn 的对账
- ImageGen / Workflow / worktree 隔离等上游改动

### 本地不变量保留

## 修复

### 数据存储位置：自定义目录重启后回退默认
切换到自定义目录后，若持久化记录只存在于旧版（pre-v0.5.4）安装目录相邻的 `CLAUDE_CONFIG_DIR` 文件夹里，新版启动只读 userData 的 `app-mode.json`，读不到便回退系统默认目录。现在启动时若 userData 无 portable 记录，会回读该旧版安装相邻记录并迁移写入 userData，后续重启直接命中；userData 已有记录时优先使用，忽略旧记录。

### 流式工具输入超时错误码映射
上游 v0.5.5 新增了工具输入阶段超时码 `STREAM_TOOL_INPUT_DURATION`，但 fork 的 WebSocket API 错误分类只内联处理了 idle / max-duration 两种，漏掉新码导致其掉回泛化的 `server_error`。改为统一复用 `classifyRuntimeErrorCode`，三种流式超时码一致映射到稳定的桌面错误码。

### 后台 Agent 嵌套终态通知缺失
拥有嵌套后台 agent 的父 agent 此前收不到该 agent 的终态 `task_notification`——`emitTaskTerminatedSdk` 只被 import 却无调用点。现在 `enqueueAgentNotification` 会为 owner-scoped 终态发出带 `owner_agent_id` 的 SDK 通知。
