# Claude Code Haha v0.7.3

本次合并上游 **Claude Code v0.6.7**（62 个提交），带来**工作区侧边对话**、**Agent Teams 启动前人工审核**、**超时自动回答**与**聊天外观设置**，并修掉超大会话打不开、并发写丢配置、IM 重连串会话等一批稳定性问题。合并过程中有 12 处 fork 定制被静默覆盖（无冲突、无类型错误），已全部找回。此外并入 v0.7.2 之后的两个修复：配置写入的掉电持久化，以及图片不支持的误判。

## 上游 v0.6.7

### 侧边对话

在输入框敲 `/btw 问题`（或选中文字后点「在侧边聊天中提问」），会在工作区右侧开一个临时对话，继承父会话的上下文和模型但独立运行，追问不会打断主任务。关闭标签或退出应用即清空。

### Agent Teams 启动前人工审核

团队方案就绪后先出「团队执行前确认」卡片，逐个成员改 Agent 预设、服务商、模型、任务归属与前置任务，可批量设置或「跟随主 Agent」，确认后才真正启动成员。启动前的成本由你把关。

### 超时自动回答

「设置 → 通用 → 自动回答问题」开启后，待回答的问题超过设定时长（1/5/10/30 分钟，默认 5）会由该会话的小模型基于对话上下文自行决策；判断不了就继续等，你任何点击或输入都会取消计时。默认关闭。

### 聊天外观

「设置 → 通用 → 聊天外观」可调聊天字体（跟随系统/无衬线/衬线/等宽）、字号（12–24px）和对话宽度（标准/宽/铺满），带预览、独立于界面缩放、按设备保存。

### 模型与供应商

- **Claude Opus 5.5**：新增 `claude-opus-5-5`（1M 上下文，支持 low 到 max 推理强度），并设为官方账号的默认模型；Claude OAuth 兼容版本对齐 2.1.281。
- **OpenAI 官方账号**：新增 GPT-6 Astra、GPT-6-Sol、GPT-6-Luna，默认模型改为 GPT-6-Sol。
- **OAuth 模型映射**：「设置 → 服务商」里每个官方账号新增「OAuth 模型映射」，可为 main/sonnet/haiku/opus/fable 五个槽位指定该账号实际可用的模型或手填别名。
- **直连 Anthropic 供应商输出预算**：不再把你配置的输出上限覆盖成固定值。
- **Grok Fable 槽位**：Fable 槽位补齐到模型映射体系，cc-switch 导入和运行时环境都能正确写入。

### 修复

- **超大会话打不开**：对话记录超过 20MB 后报「提示词过长」且无法继续的问题修复。压缩时按供应商报错里的真实 token 上限计算丢弃量并为回复预留空间；超大消息不再让整条元数据被跳过，会话标题、工作目录、模型和权限模式保持完整。
- **IM 临时断线后串成新会话**：重连失败时不再悄悄换成新会话导致上下文丢失、项目目录回默认，改为保留原会话绑定并提示稍后重试。
- **定时任务并发覆盖**：并发执行时不再互相覆盖执行时间，已删除的任务不会「复活」。
- **记忆编辑保存冲突**：保存期间继续输入，编辑器不再退出编辑态、隐藏未保存内容。
- **团队配置读到半截 JSON 会让团队在界面里消失**：所有写路径纳入文件锁并改为原子写。
- **思考型模型自动命名静默失败**：后台命名请求的 token 预算不再被思考过程耗尽。
- **Windows 上垂直滚动方向相反**。
- **CORS 预检导致 Failed to fetch**：本机来源的 OPTIONS 预检提前放行，远程来源仍严格拒绝。
- **工具参数损坏后卡住**：模型输出了非法 JSON 工具参数时不再静默退化成空参数执行，改为把明确错误回灌给模型让它自己重试。
- **会话模型选择丢失**：重开会话后模型不再回退默认；删除供应商后旧模型和推理强度不再串到新供应商。
- **切换标签 / 停止生成后聊天内容消失**：从终端或工作台切回会话保留聊天视图和滚动位置。
- **工作区侧边对话无法滚动**、**文件树操作和预览控制恢复**、**标签页之间来回切换保留聊天**。
- **图片转发**：OpenCode Go 下的 Space Bunny 形象图和 Kimi K3 图片不再丢失。
- **本地 Markdown 链接**点击后仍指向原目标；**生成的输出文件**按声明的项目根目录解析路径。
- **其他**：活动档案名过长时自动换行；`/clear` 恢复为可搜索；检查点预览不再占用聊天里的预算显示；自动回答改为纯模型决策；回退后的回合审查状态正确清理；会话发现有边界且会报告历史分页上限。

### 其他

- **Remotion 技能包**：扩展页新增 Remotion 技能包（官方 12 项技能，不含运行库和渲染器），用于用 React 制作程序化视频。
- **站点与文档改版**：官网落地页整体重做，新增四步工作流与实战案例；文档站新增 5 篇实战文档；首次访问按浏览器语言选择站点语言。

## 合并中丢失的 fork 定制：已找回

合并把部分文件整体取用了上游版本，fork 在这些文件里的增量改动随之消失。这类丢失**不产生冲突、不产生类型错误、不影响编译**，只有对应测试或人工比对才会暴露。本次找回 12 处：

- **会话子系统（`sessionService.ts`）**：`findSessionFiles` 双 push、元数据投影用错扫描器（丢掉 #1373 的超大会话修复）、effort 替换规则、会话查找退化成坏混合、两条 `isSideChatId` 守卫。
- **权限请求重放（`ws/handler.ts`）**：leader 回合结束后重放等待中的权限请求；stale-modelId 守卫的 `[1m]` 后缀口径；`interruptBoundaryPending` 守卫。
- **本地索引迁移**：`SCHEMA_V6` 重复声明与版本号冲突（`is_team_worker` 落到 v7，逐列 `hasColumn` 守卫）。
- **流重试上限**：上游给 stream 重试上限加的 `Math.min(raw, 5)` 封顶被丢，保留 fork 默认 4（relay 供应商依赖更宽的恢复窗口）。
- **文档截图**：上游删除的 10 张截图打断 fork README 引用，已回退。
- **上游新增测试用例**：冲突测试文件整体倒向一侧，静默丢弃上游 18 个新用例——回植 10 个，判为 fork 有意分歧/重复的放弃 8 个。

fork 定制点保护清单已逐项确认：README/README.zh-CN 未被覆盖、provider 墓碑（TeamoRouter / 玄枢API / FennoAI / 七牛云AI）、接口AI 可选无广告、`xhigh` 推理档、relay 重试（`get_channel_failed` / `api_error`）、`thinking` 透传、`Code Council` wordmark、GitHub 链接指向 `706412584/cc-haha`。

## 另外两个修复

- **配置写入的掉电持久化**。一次非正常关机（Kernel-Power Event 41）后 `providers.json` 字节长度正确但内容全为 0，静默抹掉 12 个已配置供应商。根因是 `writeFile(tmp) + rename` 没有 `fsync`：`rename` 只提交元数据，NTFS 可能把数据块留在页缓存里，掉电后得到一个长度正确、内容全零的文件；全仓有 9 处这样的写入。现在统一走 `atomicWrite`（重命名前先 `fsync` 临时文件），写入前对旧内容做快照；读到损坏文件时先尝试从最新快照恢复，再回退默认值。内容为空或含 NUL 字节的文件被排除在快照保留集之外，避免全零文件挤掉最后一个好快照。
- **图片不支持的误判**。此前只要会话曾带过图片，**任何** 400/422 都会被归为「模型不支持图片」，并把图片从历史里剥掉。后果是一个与图片无关的通用拒绝（参数错误、代理/格式不匹配）被报成模型不支持图片，还会静默剥离图片、污染后续每一轮。现在要求错误文本本身看起来像媒体/块类型拒绝，才走这条兜底；未命中则原样上报原始错误。
