# Claude Code Haha v0.8.4

v0.8.3 之后继续按核对清单走查，**把剩余的合并静默丢失一次补完**，并处理两处实机问题。全部对照合并前 fork 顶点（v0.7.13）逐项找回，视觉沿用 Porcelain 骨架，只补功能逻辑。

## 实机问题

- **新建会话页标题被裁切**：hero 区 `justify-end` + `overflow-hidden`，内容（印章 + 标题 + 欢迎卡片）超过窗口高度时，顶部内容被裁掉且无法滚动。改为 `mt-auto` 底部对齐 + `overflow-y-auto`，所有内容可达。ActiveSession 空态同步修复。
- **空态附件选择走原生对话框**：桌面端 `+` 菜单的「上传文件」恢复调用系统文件对话框（拿绝对路径），H5/对话框不可用时回退到浏览器 input。

## 合并静默丢失找回（第三批，含前两批遗漏）

- **流断开重试横幅**（StreamingIndicator）：恢复 `stream_disconnect` 专属文案与 `data-retry-kind` 标记，横幅视觉沿用 Porcelain。
- **流重试墙钟预算**（streamRetry）：恢复 `CLAUDE_STREAM_TRANSIENT_RETRY_BUDGET_MS` 预算控制（默认 60s）与延迟钳制；`CLAUDE_STREAM_TRANSIENT_RETRY_MAX` fork 默认 4（上限 5）的行为回归。
- **超大记录挽救**（boundedSessionHistory）：恢复 12 MiB 保留阈值与 `slimOversizedEntry`（剥离 `toolUseResult.file.base64` / `originalFile`）；精简后仍超 12 MiB 的记录以行头形式报告为遗漏，不再让坏记录永久废掉整个会话。
- **Agent 卡片四项**（ToolCallGroup）：①`useEdgeAutoExpanded` 边沿自动展开（运行开始时自动打开、用户手动折叠后不再抢开）；②`getAgentStatus` 恢复 `isStreaming` 语义——实时运行的 agent 显示 Running 而非 Starting，并透传到 `AgentCallCard`；③media-gen agent 卡片内联生成图画廊；④agent 预览超 20k 字符截断 + 「查看完整运行记录」。
- **内联图片标注提问流**（InlineImageGallery + ImageGalleryModal）：画廊头部恢复「标注并提问」按钮，标注保存后预填 composer（`-annotated.png` 附件）；恢复兄弟图片路径过滤（同消息内多图不重复注入）。
- **技能目录本地化**（SkillList）：恢复推荐技能区（11 条目录 / 9 个分类，本地化描述与分类标签）与安装/已装状态接线；零安装空态内联化。
- **插件页语言服务区**（PluginList）：恢复 LSP 插件独立分区，且修正为单次挂载（此前被 group 与 section 双重渲染）。
- **Provider 页两枚兼容性徽章**（ProviderSettings）：恢复 `provider-compat-badge-*`（推理参数不兼容警示）与 `provider-thinking-badge-*`（thinking 透传状态），删除 AruHub sponsor 徽章（去广告政策）；恢复 `proxyStepLabel` 媒体专用分支与删除时的 compat store 清理。
- **欢迎卡片图标迁移**（WelcomeTaskCards）：Material Symbols 字形（rate_review / bug_report / verified / travel_explore / hub）全部换成 lucide，通过设计系统合规测试。
