# Claude Code Haha v0.5.39

> 本版本新增 Desktop Agent Office：保留原版像素办公室、PixiJS / Spine 角色、工位拜访、气泡与表情互动，并直接映射 cc-haha 的真实 Main Agent、Team、SubAgent、Background Agent 与 Task 状态。

本说明面向最终用户与发布维护者。Desktop 版本号更新为 `0.5.39`；Agent Office 仅在 Desktop 运行时按需加载，不改变 Android / H5 的默认界面和首屏运行路径。

## Highlights

- **原版 Agent Office 视觉接入**：保留办公室背景、桌椅素材、六个 Chibi Spine 角色、四向移动、工位遮挡与动态深度排序；ai-office-react MIT notice、Spine Runtimes License 与 Chibi 示例素材许可均随对应资产一起打包。Chibi 图片仅获非商业再分发许可，因此本版本不得用于商业分发或商业用途。
- **真实 Agent 状态映射**：Office 直接消费现有 chat、CLI task、team、background task 与 Activity stores，不增加第二套任务生命周期，也不新增 HTTP polling。
- **拟人化岗位编排**：Main Agent 以“老板”身份出现；真实 Team、SubAgent、Background Agent 与 Task 分别映射为团队成员、研发专员、运维专员和项目专员，并进入稳定的六席位视图。
- **可中断的办公室趣味事件**：空闲或等待中的员工会低频闲聊、追剧或打游戏，电脑屏幕同步显示对应内容；事件仅属于场景瞬时状态，真实工作到达时立即中断，老板和工作中的员工不会被误判为摸鱼。
- **保留趣味交互**：点击人物可选择拜访其他工位或播放 Spine 表情；原版会伪造“开始工作/空闲”的手动状态按钮已移除，避免覆盖真实运行状态。
- **默认大弹窗，可切独立 tab**：顶部 Agent Office 入口默认打开大尺寸 modal；通用设置可改为独立 tab，modal 也可一键展开。
- **Office tab 单实例与返回路径**：同一 session 使用 `__office__${sessionId}`，不会重复打开；独立 tab 提供“返回会话”按钮，Office tab 不写入持久化标签列表。
- **GPU 生命周期隔离**：modal 展开为 tab 时先卸载旧 Pixi / Spine canvas，再创建新实例，避免同一 session 短暂存在两个 WebGL renderer。
- **Desktop-only lazy load**：PixiJS、Spine runtime 与 Office scene 保持在独立 `AgentOfficeRuntime` chunk 中；普通聊天和移动 H5 不加载该运行时。
- **实时信息去噪**：席位和右侧“当前任务流”只展示 live 或异常活动，完成历史仅用于统计，不会把历史任务误算成当前 AI 员工。

## 数据与交互边界

- Main Agent 状态来自目标 session 的 chat state、active tool 与 status verb。
- Team、SubAgent、Background Agent 和 CLI Task 复用统一 `SessionActivityModel` 的既有分类和状态语义。
- 六个 Pixi entity ID 保持稳定；真实活动只替换席位姓名、状态、任务和 source key，避免动态 Agent ID 触发 WebGL 对象树重建。
- 场景层只拥有位置、路径、拜访、气泡、表情和低频趣味事件等瞬时动画状态；任务状态仍以现有 Zustand stores 为唯一权威来源。
- Activity snapshot 更新不会中断进行中的拜访；动画完成后恢复到最新真实状态。

## 展示方式

- 默认：在当前会话上打开大尺寸 Agent Office modal。
- 设置：`设置 → 通用 → Agent Office` 可切换为独立标签页。
- modal 中可使用“展开为标签页”；旧 canvas 会先销毁。
- Office 独立 tab 可使用“返回会话”回到来源 session，并关闭自身。
