# Claude Code Haha v0.9.0

合并上游 NanmiCoder/cc-haha **v0.7.7 + v0.7.8**(v0.7.6..v0.7.8)，并把索引会话列表的每行磁盘 IO 从串行改成并发。

## 上游带来的新东西

- **外出连接更稳**（#1862）：外出时保持电脑唤醒开关默认开启，桌面服务重启沿用原 cloudflared 隧道与地址，隧道地址变化时同 Wi-Fi 手机自动切换，iPhone 收到「电脑地址已更新」推送。
- **手机 P2P 直连**（#1844 / #1859）：外出连接页新增「允许手机直连（P2P）」开关；打包版也能直连，手机回前台原地续会话只补收增量。需要手机 App 0.1.4。
- **回合运行中切换执行权限**（#1851）：盾牌选择器在任务跑时也能在 ask / skip permissions 之间立即切换。
- **Claude Fable 5.2**（#1874）：新增 `claude-fable-5-2`，1M 上下文 / 128K 输出；`fable` 别名指向 5.2。
- **ChatGPT Official 按模型设上下文窗口**（#1869）：模型映射面板每行可加「上下文窗口（可选）」输入。
- **微信媒体投递与连接恢复**（#1819）：通道状态面板 + 本地图片 / 文件按限额回传，支持 `/delivery`、`/retry` 补发。
- **上游修复**：长思考渲染不卡顿（#1858）、跨会话消息串台（#1843）、超大消息不再静默丢失（#1811）、编辑供应商不再悄悄改路由（#1835）、错误分类更准（#1870 / #1868 / #1836）、带版本号 Base URL 不再被强插 `/v1`（#1852）、单张坏图不再卡死会话（#1853）、Memory 重载真正重读磁盘（#1834 / #1867）、worktree 会话恢复（#1854）、附件托盘限高内部滚动（#1850 / #1867）、归档会话菜单定位（#1848）、团队成员页面回答问题（#1849）、安全与登录（#1821）、插件 marketplace 列表（#1792）、IM 连接可靠性（#1815）、手机端（#1857 / #1855）。

## 本版修复（合并回归）

合并 v0.7.7 / v0.7.8 过程中遗留的 fork 侧残留缺陷，逐一清理：

- **`sessionService` 重复 import 与重复声明**（`06709dc29`、`4cc7eed6c`）：冲突解决把 `readHistoryContexts`、`recoverBoundedSessionHistory`、`parseSessionCollaborationEnvelope`、`splitSessionReferenceContext`、`getSideChat / isSideChatId / sideChatSummary`、`isShutdownTeamPrompt`、`isTeamLeadNotice` 各 import 两次；`MessageEntry.bodyTruncated` 与 `historyRecoveryCache` 重复声明。
- **fork reactive-compact 被上游门控回退**（`e22a94ef9`）：`src/query.ts` 被改回 `feature('REACTIVE_COMPACT')` 门控，sidecar 构建仅启 `TRANSCRIPT_CLASSIFIER` 时门控为 null，禁用了 fork 自 `f42fd0905` 起一直开启的 PTL 恢复路径。恢复 `import *`，上游 `compactAfterPromptTooLong` 作为二次兜底。
- **`isCuHelperAvailableForServer` 丢失**（`c072328fb`）：`src/server/api/computer-use.ts:687` 调用，macOS 应用枚举为空时 `ReferenceError`。补回定义。
- **`prePlanPermissionMode` 缺失**（`e735729f8`）：`SessionMetadataPatch` 类型漏声明该字段。
- **测试与文档残留**：`localIndex/searchContentProjector.test.ts` 缺 `stat` 类型 import；`EmptySession` 的 `imageCompress` 在 jsdom 无 2D context 时短路；`docs/*/code-signing.md` 链接文字从 `NanmiCoder/cc-haha` 改回 `706412584/cc-haha`。

## 本版新增（fork 侧性能优化）

- **索引会话列表水合并发**（`01abbf97d`）：`hydrateIndexedSession` 每行内部串行 await `fs.realpath` / `fs.stat` / `pathExists`,50 行分页等于 150–200 次串行磁盘 IO。改为 `Promise.all` 并发，每行保留 `try/catch` 单行容错；`pathExists` 的 Promise 缓存原本就为并发设计。降级（degraded）列表路径保持串行。
