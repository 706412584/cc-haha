# Code Council v0.5.52

> 本版本吸收上游 cc-haha v0.5.1 的客观修复，同时保留 Code Council 的本地产品行为，并修复会话恢复与连续服务过载重试的可靠性问题。

## 重点更新

### 上游 v0.5.1 集成

- 吸收上游 Desktop、聊天、Provider、附件、安全边界、持久化与发布流程相关修复。
- 保留 Mobile/H5 与 Desktop 隔离，以及图片 path-only、延迟 Base64 和预览性能策略。
- 保留十套主题、Code Council 品牌、Grok effort/thinking 与会话内 Provider 切换行为。

### Agent 完成通知恢复

- 会话恢复时不再将超过 24 小时的 pending Agent completion 重新注入当前对话，避免多天前的任务终态污染新回合。
- 同日崩溃恢复仍可继续投递未确认通知，并保留 Agent epoch、ack、requeue 与终态回收语义。

### API 重试状态

- 429、503 和 529 的每次重试都会更新 Desktop 状态，连续服务过载时重试次数与倒计时不再停留在第一次。
- 其他短暂 5xx 仍沿用现有降噪阈值，避免重复错误淹没会话。

### Desktop 与 Windows

- Windows 自动升级后继续保持用户原有 app mode。
- 修复 Windows 项目 Agent 文件更新的安全打开方式，并继续拒绝符号链接与越界路径。
- 修复 Stop settle、Composer location 工具栏重复项和 Workspace preview reveal 状态。
- Provider 主模型会优先继承匹配模型槽位的 capabilities，避免 thinking/effort 能力判断失配。
