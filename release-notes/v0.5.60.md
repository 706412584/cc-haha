# Code Council v0.5.60

> 本版本修复后台任务停止确认后 UI 不更新问题：服务器确认任务已停止时，桌面端立即将任务状态更新为已停止，而不再等待永远不会到来的 CLI 终态通知。

## 重点更新

### 后台任务停止修复（核心缺口）

- `background_task_stopped` 消息处理器现在同时将 `backgroundAgentTasks` 中对应任务的状态标记为 `stopped`，而不只是清除"停止中"标记。
- 根因：CLI 进程已死时，服务器会正确回发 `background_task_stopped`（判断"任务必然已死"），但之前的处理器只清除了 UI 防重复点击锁，任务状态只能靠 CLI 的终态通知转换。CLI 已死，通知永不到来，于是任务永久卡在"运行中"。
- 修复后：服务器的确认是权威结论，收到即立即更新状态。点击停止后 UI 将正确显示已停止。
