# Claude Code Haha v0.5.43

## Rule Federation

- Project Rules 现在统一发现 Claude Code、Cursor、Windsurf 与 GitHub Copilot 的项目规则，包括目录规则和各工具的项目级全局指令文件。
- 规则通过共享规范化契约展示 provider、原始路径、canonical path、内容 fingerprint、作用域、标签与 provenance。
- Claude 原生规则保持最高优先级；跨 IDE 的同内容或同 canonical path 规则会被确定性标记为重复、冲突或已由 Claude 原生规则覆盖，不再静默覆盖。
- Desktop Project Rules 页面继续支持创建和打开 Claude 规则，并新增外部规则来源、provenance、冲突状态以及“仅此会话”“此项目始终启用”“忽略”三种导入决策。
- 导入决策写入项目本地 `.cc-haha/rule-federation.json`，同时加入仓库本地 `.git/info/exclude`；不会修改外部 IDE 规则、不会自动提交。读取和写入会拒绝 traversal、项目外路径与 symlink/junction 越界。
- 已启用的外部规则复用现有 Claude memory loader，支持 `.md`/`.mdc` 解析；外部规则先加载，Claude 原生规则后加载并保持更高优先级。

## API stream retry

- stream 创建阶段与消费阶段现在都会对无 HTTP status 的 `api_error`、`overloaded_error` 和 `upstream_error` 进行有限重试。
- 两个阶段复用有界指数退避和 AbortSignal 语义；确定性 4xx 仍不会重试。
- 重试耗尽后的用户错误文案会说明已执行的重试次数，并在 SDK 提供时保留 request ID；request ID 不拼入诊断正文。
- Desktop 普通 HTTP client 未修改，因为真实错误路径位于 Anthropic stream 创建和消费链路。
