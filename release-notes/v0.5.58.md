# Code Council v0.5.58

> 本版本同步上游 v0.5.4（68 个提交），带入动态 Workflow 编排、Agent Teams 协作工作台、Worktree 会话详情、Git 分支快捷创建、内置 Agent 模型覆盖等重大功能；同时修复多项 Provider、会话、UI 稳定性问题，并通过全部测试门禁。

## 重点更新

### 动态 Workflow 编排（全新功能）

- 新增 `feat(workflows): dynamic workflow orchestration end to end` — 支持运行时动态定义和调度多步骤工作流，串行/并行步骤均可在 Desktop 端可视化跟踪。
- `fix(workflows): save desktop runs and surface cached activity` — 工作流运行结果持久化到 Desktop，Activity 面板展示缓存状态。
- `fix(workflows): deduplicate resumed activity runs` — 恢复的工作流不再产生重复的 Activity 条目。

### Agent Teams 协作工作台

- `feat(agent-teams): add collaborative workbench` — 全新 Agent Teams 工作台，多 Agent 协同任务可在 Workbench 标签页内并排跟踪。
- `feat(teams): rebuild the collaborative workbench` — 工作台重构，成员卡片、任务状态与 Activity 面板深度联动。
- `fix(teams): report real member and task state in the workbench` — 工作台展示真实成员在线/任务状态，而非占位符。
- `fix(teams): stabilize activity, history, and lifecycle` — 修复成员 Activity 丢失、历史记录错位、生命周期事件错序的问题。
- `fix(teams): synchronize member tasks and activity` — 成员任务与 Activity 面板保持严格同步。
- `fix(teams): align task status and slash entry` — TaskStatus 枚举与 slash 入口对齐，消除空引用。
- `fix(desktop): isolate Agent Teams activity and share session UI` — Agent Teams Activity 与普通 Session Activity 独立隔离，Session UI 在 Teams 场景下复用。
- `fix(desktop): render teammate Markdown and sync member activity` — 队友消息支持 Markdown 渲染，Activity 实时同步。

### Worktree 与会话管理

- `feat(desktop): show worktree session details` — 在会话列表中展示 Worktree 分支、路径等详情。
- `feat(desktop): create git branches from the launch picker (#1190)` — 启动选择器中可直接新建 Git 分支，无需切换到终端。
- `fix(desktop): retain newly created branch for session launch` — 新建分支后不再被清除，启动会话时正确绑定。
- `fix(desktop): confirm newly created launch branches` — 新建分支确认流程修复，避免空分支名问题。
- `fix(sessions): keep worktree paths authoritative` — Worktree 路径不再被 session 重启覆盖。
- `fix(desktop): protect unloaded sessions from tab cleanup (#1217)` — 切换 Tab 时未加载的会话不会被错误清理。

### 内置 Agent 模型与推理覆盖

- `feat(agents): override built-in agent model and effort` — 内置 Agent（如 Explore）现在可以在 Agent 设置中独立指定模型与推理强度，不再强制继承全局设置。
- `fix(agents): stream child runs in shared UI` — 子 Agent 运行的流式输出在父会话 UI 中实时展示。
- `fix(agents): reload built-in overrides in active sessions` — 已开启的会话在更新 Agent 设置后立即生效，无需重启。
- `fix(tasks): scope a subagent's task list to the agent` — 每个 Subagent 只看到自己的任务列表，不再混入父 Agent 任务。

### Provider 与模型

- `feat(provider): default Grok Official to grok-4.6 with xhigh effort` — Grok Official 预设默认切换为 grok-4.6，默认推理强度改为 xhigh。
- `feat(provider): surface Atlas Cloud referral link in the picker` — 模型选择器中展示 Atlas Cloud 推荐链接。
- `fix(effort): stop clamping Grok xhigh effort to high` — 修复 Grok xhigh 档被错误降级为 high 的问题。
- `fix(provider): keep Grok effort editable for live-catalog models` — 动态目录中的 Grok 模型支持手动修改推理强度。
- `fix(provider): strip protected thinking after model switch (#1215)` — 切换模型后自动清除受保护的 thinking 内容，避免 API 拒绝。
- `fix(server): sync resolvedModelId when opus[1m] migrates to claude-sonnet-5` — `opus[1m]` 别名迁移到 claude-sonnet-5 时，resolvedModelId 同步更新，不再留存旧 ID。

### Desktop UI 与交互

- `feat(desktop): add custom project display names` — 支持为项目自定义显示名称，与实际路径解耦。
- `fix(desktop): add Ultracode keyword controls` — Ultracode 模式新增关键词控制开关。
- `fix(desktop): reuse model picker for agent settings` — Agent 设置页复用标准模型选择器，UI 风格统一。
- `fix(desktop): compact user message image previews` — 用户消息中的图片预览更紧凑，减少滚动区占用。
- `refactor(desktop): compact completed-turn footer` — 已完成轮次的底部操作栏更紧凑，减少视觉噪音。
- `refactor(desktop): collapse the chat transcript into activity groups` — 聊天记录按 Activity 分组折叠，长工具调用链不再撑开页面。
- `refactor(desktop): flatten nested tool activity` — 嵌套工具 Activity 展平展示，层级更清晰。
- `refactor(desktop): fold settled tool activity into a counted summary` — 已完成的工具组折叠为计数摘要，减少视觉干扰。
- `fix(desktop): keep turn progress feedback visible` — 流式过程中的进度指示不再被提前隐藏。
- `fix(desktop): streamline AgentTeams workbench` — Workbench 布局精简，移除冗余分隔符和占位区域。
- `fix(desktop): recover live subagent runs and split the team report from the workbench` — 恢复会话时在途 subagent 运行不丢失；团队报告从 Workbench 分离为独立面板。
- `fix(desktop): show undo for unverified-only turns` — 仅含未校验步骤的轮次也显示撤销按钮。
- `fix(desktop): preserve effort and repeated turns (#1197)` — 修复切换模型后 effort 被重置、重复轮次被合并的问题。

### H5 与移动端

- `fix(h5): show AskUserQuestion before tool stream completes (#1220)` — H5 端工具流尚未完成时，AskUserQuestion 权限弹窗提前弹出，不再等到流结束。

### Adapters

- `fix(adapters): resolve project names after /projects picker` — IM Adapter 在 `/projects` 选择后正确解析项目名称。
- `fix(auth): align Claude OAuth model and recovery` — Claude 官方 OAuth 登录流程与 token 恢复对齐，修复偶发登录失败。

### 其他修复

- `fix(compact): align context usage across providers (#1162)` — context compaction 触发阈值在所有 Provider 下统一计算。
- `fix(rewind): stop blocking undo on unrecognized tools (#1192)` — 含有未知工具的轮次不再阻止撤销操作。
