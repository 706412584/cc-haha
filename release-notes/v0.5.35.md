# Code Council 0.5.35

## 修复

- 修复 assistant 尾部消息原地增长时，消息数量不变导致聊天区不继续自动跟随的问题。
- 恢复 0.5.33 的近底部滚动体验：用户只轻微上滑查看时，当前会话运行中仍可继续跟随新输出。
- 修复非运行态会话的自动滚动边界：当前对话已空闲时，即使距离底部在 120px 阈值内，尾部消息或元数据更新也不会把视图强制滚到底部。
- 保留显式用户动作：发送新消息、点击 `Latest` 仍会跳到最新位置。

## 验证

- `MessageList` 自动滚动回归测试覆盖：尾部 assistant 增长、轻度回看、近底部新输出、Latest 按钮、空闲态不自动滚动。
- 桌面端 lint、测试和构建已通过验证。
