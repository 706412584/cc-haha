# Claude Code Haha v0.8.7

合并上游 NanmiCoder/cc-haha **v0.7.1**（29 个提交）。本版以 fork 为基底吸收上游：进程回收、子代理并发限制、Fast mode、冷历史去重等；49 个冲突全部解决，fork 定制逐项验证存活。

## 上游带来的新东西

- **进程回收**：关闭会话时连同其 CLI 与 MCP 进程一起回收，不再留下孤儿进程（#1501）。
- **子代理并发限制**：设置 > 通用新增 `maxConcurrentSubagents`；转后台时续接前台已发出的迭代器，不重启 worker、不丢消息（#1506）。
- **Fast mode**：ChatGPT OAuth 会话可在设置里开启，请求走精简提示词（#1502）。
- **冷历史去重**：恢复历史时不再重复流式 thinking 与回复（#1476）。
- **自动更新开关**：可关闭自动更新，更新提醒尊重 deferral（#1482）。
- **CSV/TSV 表格预览**：工作区里直接以表格查看（#1505）。
- **搜索索引与实时转录**：索引写入迁到 worker，流式转录更顺（#1493 / #1498）。
- **性能**：长任务流式输出不再冻结窗口（#1503/#1480）。

## fork 特性全部保留（逐项嫁接回上游骨架）

- **品牌**：Code Council 文案、README、关于页；全库链接指向 `706412584/cc-haha`。
- **中转韧性**：relay 重试（`get_channel_failed` / `api_error` 5xx）、墙上时钟预算、thinking 透传（`roundTripReasoningContent` 无条件透传）。
- **推理档位**：K3 等模型的 `xhigh` 档位保留。
- **Provider 策略**：TeamoRouter / 玄枢API / FennoAI / 七牛云AI 墓碑保留；接口AI 可选、无广告。
- **编排与工作台**：编排提示词 / 项目规则 / Trace 页三个 tab、+ 菜单编排开关、Agent Office、统一活动面板、TabBar 双箭头与滚轮行为、会话右键菜单（导出 JSONL / 复制路径 / 在文件夹中显示）。
- **H5**：cloudflared/Pinggy 隧道 UI。
- **其它**：图片标注、假 tool_use 泄漏检测、团队 strip 显隐、技能与插件推荐目录、MCP 市场、侧聊守卫。
