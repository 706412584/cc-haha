# 发布图与群文案提示词

使用最新 release markdown 的**中文原文**作为唯一内容依据。写给已经在使用 Claude Code Haha 的微信群用户，突出他们最能感受到的变化，避免把每条 commit 都挤进图里。

**长图视觉提示词：**1080px 宽、适合手机纵向阅读的简体中文版本更新图。顶部深炭色 Hero 约 230px，只放产品名、版本号和「新版本发布」，无插画、无大图、无大块留白；紧接着进入本版实际有内容的功能或修复区。主体为暖白纸色，深色标题、陶土红小标记、简洁双列功能卡、单列修复清单。纯修复版不要出现「这次新增」或空功能卡。贡献者区展示从 GitHub 实际取得的圆形头像、准确 ID 和对应贡献。正文由确定性字体排版完成，不能依赖生成模型拼写文字或绘制头像。按内容自然增长高度，不压缩字号来塞入更多条目。

**提炼提示词：**从发布说明选最多 4 项核心功能、最多 9 项用户能理解的修复；没有的类别保持为空。每项标题尽量不超过 14 个汉字，说明用一句话讲清“现在能做什么”或“之前的问题如何改善”。优先考虑群友直接感受到的变化，避免用开发者内部修复挤掉有用的用户功能。保留必要条件，例如“在设置中开启后”、超时选项、适用平台、临时性或签名状态。模型更新可合并为一个区块。未署名的修复不强行归给贡献者。

**群文案提示词：**用自然、简短的群聊语气，最多三句话；写出版本号和最重要的两项变化，最后引导看图。有本版署名贡献者时感谢代码贡献；没有时感谢反馈与支持。只有用户明确说这些贡献者是群成员时才称他们为“群友”。不要把图内清单再抄一遍；不要虚构下载链接或给未核实的 GitHub ID 加 `@`。
